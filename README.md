# Enterprise Equipment Maintenance Management System - Frontend

## Overview
An internal full-stack web application designed for enterprise equipment management, featuring internal access control and maintenance scheduling workflows. Engineered and optimized using **Claude Code** as an AI development assistant.

## Features

* Internal Authentication & Role-Based Access Control (JWT)
* Equipment Tracking & Inventory Management
* Maintenance Scheduling & Cancellation Workflows
* Service History & Equipment Status Monitoring
* Containerized Deployment (Docker & Docker Compose)
* Automated CI/CD Pipeline (GitHub Actions)

## Technologies

* Next.js
* Tailwind CSS
* Redux Toolkit
* React Query / Axios
* Claude Code (CLI AI Development Assistant)
* Docker & GitHub Actions (CI/CD)
